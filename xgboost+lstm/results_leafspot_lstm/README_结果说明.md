## 建模说明
- 模型：按病害分别训练 3 个残差式 LSTM，每个模型同时预测“发病率 + 病情指数”的相对增量。
- 时序输入：目标调查日前连续 28 天的原始气象序列。
- 过程输入：生育期编码、调查间隔、有效积温_GDD、近3/7/14天降水、连续降雨天数、降雨间歇长度、近3/7/14天相对湿度等。
- 评估方式：留一监测点交叉验证（leave-one-site-out），并采用逐次滚动一步预测生成发病曲线。
