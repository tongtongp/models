# 模块化拆分说明（不改原始脚本）

已在本目录完成按功能拆分，原始文件 `lstm_leafspot_analysis.py` 未修改。

## 文件结构（按 01~06 编号）

1. `01_config.py`  
   常量配置、路径配置、标签映射、全局随机种子与目录初始化。

2. `02_data_cleaning.py`  
   数据解压、docx 读取、Excel 日期处理、气象读取、调查聚合、CSV/Excel 导出。

3. `03_feature_engineering.py`  
   过程特征构建、21天气象序列构建、训练数组构建、标准化函数。

4. `04_model_training_testing.py`  
   LSTM 模型结构、训练、验证、滚动预测、指标计算。

5. `05_analysis_and_reporting.py`  
   相关性分析、置换重要性、绘图、文本摘要与报告生成。

6. `06_main_pipeline.py`  
   主流程调度：清洗 -> 特征 -> 训练/测试 -> 分析 -> 导出。

## 运行方式

直接运行：`06_main_pipeline.py`

## 备注

- 为满足“文件名前缀 01/02/03...”要求，模块之间使用动态加载方式。
- 代码内已加入分段编号注释（如 `[03.4]`、`[06.2.7]`），便于答辩讲解与定位。
